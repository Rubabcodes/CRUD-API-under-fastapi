# CRUD API Under FastAPI

A simple RESTful API built with **FastAPI, SQLAlchemy, and Pydantic** to perform Create, Read, Update, and Delete (CRUD) operations on tasks.

## Features

* Create, retrieve, update, and delete tasks.
* Database management using SQLAlchemy.
* Data validation with Pydantic.
* Interactive API documentation with Swagger UI.

## Technologies

Python, FastAPI, SQLAlchemy, Pydantic, and Uvicorn.

## Run the Project

```bash
uvicorn main:app --reload
```

Open `http://127.0.0.1:8000/docs` to explore and test the API.
